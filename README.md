![Quantum Adventure Logo](https://ayushdocs.github.io/Ayush-Quantum-Adventure/logo.svg)

## 🔬 Interactive Labs

Explore 10 high-fidelity simulations, optimized for both desktop and mobile:

### 🌐 Topological Matter

- **[Berry Curvature](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/berry-curvature)**: Visualize momentum-space topology and Chern numbers.
- **[Quantum Hall Effect](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/quantum-hall)**: Edge states and Landau levels in 2D electron gases.
- **[Graphene & Dirac Lab](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/graphene)**: Honeycomb lattice dynamics and the Klein Paradox.
- **[Weyl Semimetal](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/weyl-semimetal)**: 3D Brillouin Zone nodes and surface Fermi Arcs.

### 🧲 Superconductivity & Magnetism

- **[Superconductor Explorer](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/superconductor)**: BCS gap and Meissner Effect transitions.
- **[Andreev Reflection](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/andreev-lab)**: Superconductor-metal interfaces and Cooper pair splitting.
- **[Majorana Fermions](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/majorana-fermion)**: Split electrons and non-Abelian braiding statistics.
- **[Altermagnetism](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/altermagnetism)**: The third class of magnets with massive spin splitting.

### 📡 Spectroscopy & Dynamics

- **[X-Ray Diffraction](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/xray)**: Ewald sphere geometry and crystal structure solving.
- **[Diatomic Vibration](https://ayushdocs.github.io/Ayush-Quantum-Adventure/#/learn/diatomic)**: Hydrogen vs. Carbon Monoxide phase-space dynamics.

## 🛠️ Tech Stack

- **Frontend**: React (Context API, Hooks)
- **Visualization**: Three.js (@react-three/fiber), Canvas API, SVG
- **Styling**: Vanilla CSS, Glassmorphism, Responsive Design (Mobile-First)
- **Icons**: Lucide React
- **Build**: Vite

## 🚀 Getting Started

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/ayushdocs/Ayush-Quantum-Adventure.git

# Install dependencies
npm install

# Start the dev server
npm run dev
```
